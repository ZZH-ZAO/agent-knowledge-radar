# Pain Points（行业痛点库）

这里存放 Agent / 大模型应用的行业共性痛点文档。

痛点不是“某个项目遇到了什么 bug”，而是要回答：

- 行业内反复出现的结构性问题是什么
- 这些问题在 GitHub、优质博客、论文、旧文档和你的项目里分别有什么证据
- 优秀项目是怎么解决的
- 这些做法有没有共性
- 我们能从中得到什么启发
- 当前项目下一步应该怎么做

痛点文档的默认来源包括：

- GitHub 优质项目
- 优质技术博客
- 论文和研究资料
- 你提供的旧文档和面经
- 当前知识库里的项目沉淀

当前痛点页面由 `scripts/build_knowledge_index.py` 生成，但结构已经按“行业痛点 -> 证据来源 -> 共性做法 -> 数据信号 -> 启发 -> 行动项”设计，后续会逐步迁移成独立 Markdown 文档。

建议后续每新增一个高质量来源，都补一条：

```text
行业痛点 -> 证据项目/资料 -> 共性解法 -> 数据信号 -> 当前项目行动项
```

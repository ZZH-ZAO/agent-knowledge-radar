# 优质技术博客

这里沉淀的是“值得当证据和方法来源使用”的博客、产品文档和工程文章。

它和单项目沉淀的区别是：

- 单项目沉淀更像“完整案例”
- 这里更像“关键做法与判断依据”

这里后续重点承担三件事：

- 学外部优质文章是怎么立题、推进、收束的
- 学大公司工程文章怎么写约束、取舍和证据
- 学高信号博主怎么把技术内容写得能读、能说、能马上拿去用

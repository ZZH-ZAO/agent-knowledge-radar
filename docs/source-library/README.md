# Source Library（外部资料源）

这里不是“链接收藏夹”，而是平台自动进化的输入层。

它的目标不是先把资料堆进知识库，而是先判断三件事：

1. 这份资料到底解释了什么行业问题。
2. 它提供的是观点、证据，还是可迁移做法。
3. 它应该回写到 `项目 / 方案 / 痛点 / 面试` 里的哪一层。

## 1. 目录结构

```text
source-library/
  GitHub 优质项目/
  优质技术博客/
  论文研究资料/
  用户提供文档/
```

## 2. 资料进入平台后的流转

```text
资料源
  -> 识别行业痛点
  -> 判断证据强度
  -> 提取优秀做法
  -> 关联已有项目与 patterns
  -> 更新 pain-points
  -> 更新 patterns
  -> 生成当前项目行动项
```

## 3. 合格资料标准

- 能解释一个 Agent / 大模型工程里的共性问题，而不只是展示功能。
- 能提供证据、结构或案例，而不只是抽象观点。
- 能和已有项目、痛点或方案发生关联。
- 能反哺当前项目，输出至少一个明确行动项。

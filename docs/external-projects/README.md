# External Projects（外部项目沉淀）

这里存放单个优秀项目的沉淀文档。现在按“看文件夹名就知道项目类型”的方式归档。

## 分类目录

| Folder | 用途 |
| --- | --- |
| `完整开源 Agent 平台样本/` | 完整开源 Agent 平台，适合学习产品级架构、扩展生态、治理和工程化 |
| `Claude Code 生态与源码样本/` | Claude Code 官方、生态、资料和源码分析相关项目 |
| `MCP 工具与浏览器自动化样本/` | MCP server、浏览器自动化、工具协议和工具运行时案例 |
| `AI 前端设计规范样本/` | 让 Agent 生成前端时保持视觉风格和设计质量的项目 |
| `AI 前端设计生成样本/` | 使用 GPT Image 2、UI mockup、截图对照辅助生成前端页面的项目 |
| `前端风格与工作台样本/` | 高质量组件系统、后台模板、数据面板和工作台风格参考 |
| `旧体系迁移项目样本/` | 从 `.claude/docs` 迁移来的历史项目沉淀，保留旧路径证据，并统一改成深度学习结构 |
| `待分类项目池/` | Project Radar 新生成但尚未人工归类的沉淀草稿 |

## 旧体系迁移说明

`.claude/docs` 不再作为新沉淀落点。旧内容已经以“项目案例”的方式收束到 `旧体系迁移项目样本/`，每份文档都会保留旧路径证据，并补充：

- 这件事到底考什么
- 口语版回答
- 可迁移工程问题
- 常见误区
- Trade-off 与边界
- 当前项目行动项
- 面试官追问

## 命名规则

项目文档仍使用稳定文件名：

```text
{owner}-{repo}.md
```

目录负责表达项目类型，文件名负责保持脚本和索引稳定。

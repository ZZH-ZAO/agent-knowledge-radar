# AI 前端设计生成样本

这里放使用图像模型、视觉提示词、UI mockup、截图对照和前端重建流程来辅助生成页面的项目。

它和 `AI 前端设计规范样本/` 的区别是：

- `AI 前端设计规范样本/` 关注如何把设计规则写成 `DESIGN.md` 这类仓库资产。
- `AI 前端设计生成样本/` 关注如何用 GPT Image 2 等图像模型先生成视觉稿，再转成 HTML/CSS/React 页面。

当前样本：

- [oil-oil/draw-ui](oil-oil-draw-ui.md)：Claude Code skill，用 GPT Image 2 生成 UI mockup，并指导截图到 HTML/CSS 的重建流程。

# Routing Guide

Use this file when deciding how to combine the other Agent skills.

## If The User Says

### “Analyze this Agent project”

Start with:

- `agent-architecture-review`

Then optionally add:

- `agent-feature-roadmap` if the user also asks what to build next

### “How should I build a similar system?”

Start with:

- `agent-platform-design`

Then optionally add:

- `agent-architecture-review` as supporting evidence from existing systems

### “What should this project do next?”

Start with:

- `agent-feature-roadmap`

Then optionally add:

- `agent-architecture-review` if current bottlenecks are unclear

### “Compare these Agent projects”

Use:

- `agent-architecture-review` as the main comparison frame
- `agent-platform-design` to extract reusable lessons
- `agent-feature-roadmap` to explain where each project should go next

## Recommended Default Flow

1. understand current system
2. extract reusable design lessons
3. recommend staged next steps

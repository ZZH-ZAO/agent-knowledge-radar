# Layer Questions

Use these questions to deepen the review.

## Runtime

- What truly drives execution?
- Where is state held across turns?
- How are actions fed back into later reasoning?

## Prompt

- What is stable vs dynamic?
- How is prompt cache preserved or broken?
- Are temporary reminders separated from core rules?

## Tool Runtime

- Is this just function dispatch or a governed runtime?
- How are permissions decided?
- How are concurrency and side effects managed?

## Workflow

- Which orchestration exists at turn, session, background, and multi-agent level?
- Are async and background paths first-class or bolted on?

## Retrieval

- What kinds of knowledge are retrieved?
- Is retrieval structured, semantic, hybrid, or ad hoc?

## Memory

- What gets remembered?
- When is memory recalled?
- Is there consolidation or pruning?

## Multi-Agent

- Who coordinates?
- Who owns final responsibility?
- How do results and status flow back?

# Trigger Signals

Use these as evidence-based upgrade triggers.

## Add Memory When

- preferences repeat across sessions
- project rules are constantly re-explained
- session-to-session continuity matters

## Add Retrieval When

- relevant knowledge sits outside the active context
- file search stops being enough
- external documents or policies matter to output quality

## Add Multi-Agent When

- subtasks are naturally parallelizable
- one coordinator can synthesize results
- verification, exploration, or implementation can be split cleanly

## Add Team Features When

- multiple people rely on the same knowledge base
- collaboration spans sessions or surfaces
- memory becomes a shared asset, not just a private preference store

## Add Platform Controls When

- risky features are growing
- rollout must be controlled
- debugging production behavior matters
- the system is becoming expensive or operationally complex

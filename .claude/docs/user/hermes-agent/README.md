## Recommended Reading Order

1. `analysis.md`
   先看 Hermes Agent 为什么不是普通 CLI agent，而是把学习闭环、跨平台入口、长期记忆、计划调度和研究训练都塞进同一系统里的“长期运行型 Agent 工作台”。
2. `vs-deer-flow-vs-claude-code.md`
   再看它和 `deer-flow`、`claude-code` 的差异：谁更像通用 harness，谁更像平台产品，谁更像长期运行型 workbench。
3. `what-to-borrow-for-this-workbench.md`
   最后看如果回到你当前这套 `.mcp + docs + memory` 工作台，Hermes Agent 最值得借哪些点，哪些又暂时不该照搬。
4. `workbench-upgrade-plan.md`
   如果准备真的动手改造，再看这份实施规划：分阶段目标、交付物、优先级、风险和验收标准。

## What This Case Is Best For

- 学“会话型 Agent”如何长成“长期运行型 Agent”
- 学 memory、skills、session search、cron 如何形成闭环
- 学 CLI、gateway、TUI、ACP 多入口如何共用同一 Agent 底座
- 学研究型 Agent 如何兼顾真实产品能力与 RL / trajectory 数据产出

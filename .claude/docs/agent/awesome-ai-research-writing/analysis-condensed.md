2. skill adoption guidance
3. input/output expectation framing

- model-selection guidance is temporally unstable

## Best Reuse Scenarios

- when building a knowledge-first repository

## Do Not Use As Main Reference For

- runtime architecture
- multi-agent coordination
- tool execution substrate
- memory-system implementation
